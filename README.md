# Лиды без касаний

Дашборд MyGenetics для руководителей B2C: открытые лиды групп продаж B2C МСК и НСК, по которым больше 48 часов не было нашего касания, в разрезе по менеджерам.

**Касание** — наше исходящее действие: сообщение менеджера или бота в чат Открытой линии либо звонок. Сообщения клиента касанием не считаются. Если клиент написал позже нашего последнего касания, лид помечается «клиент ждёт ответа».

## Как работает

- `collector.js` раз в 15 минут собирает снимок из Bitrix24 через входящий вебхук: лиды, привязанные чаты Открытых линий, последние сообщения и звонки. Сервер только читает, в Bitrix ничего не пишет.
- `server.js` хранит последний удачный снимок в памяти и отдаёт страницу и `/api/snapshot` под HTTP Basic-авторизацией.
- `public/index.html` запрашивает снимок раз в минуту и пересчитывает время без касаний на месте.

Внешних зависимостей нет, нужен Node.js 22+.

## Переменные окружения

| Переменная | Обязательна | По умолчанию | Что это |
|---|---|---|---|
| `BITRIX_WEBHOOK` | да | — | URL входящего вебхука, `https://<портал>.bitrix24.ru/rest/<id>/<ключ>/`. Права: crm, imopenlines, im, user, department. |
| `DASHBOARD_PASSWORD` | да | — | Пароль для входа на дашборд. |
| `DASHBOARD_USER` | нет | `mygenetics` | Логин для входа. |
| `DEPARTMENTS` | нет | `256,198` | ID подразделений Bitrix через запятую (Группа продаж B2C МСК и НСК). |
| `THRESHOLD_HOURS` | нет | `48` | Порог «без касаний», часов. |
| `REFRESH_MINUTES` | нет | `15` | Как часто собирать данные. |

Вебхук и пароль задаются только в переменных Railway, в репозиторий их не коммитим: репозиторий публичный.

## Railway

1. Variables: задать `BITRIX_WEBHOOK` и `DASHBOARD_PASSWORD`.
2. Settings → Networking → Generate Domain.
3. Healthcheck path: `/healthz`, он отвечает без пароля и без данных.

Первый сбор после запуска занимает около 30 секунд, всё это время страница показывает «Первый сбор данных».

## Локальный запуск

```sh
BITRIX_WEBHOOK=... DASHBOARD_PASSWORD=... npm start
# http://localhost:3000
```
