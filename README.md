# Без касаний B2C

Дашборд MyGenetics для руководителей B2C: открытые **лиды** и **сделки воронки «В2С Продажа»** менеджеров групп продаж B2C МСК и НСК, по которым давно не было нашего касания: у лидов — больше 48 часов, у сделок — больше 30 дней. Вкладки переключают лиды и сделки; по умолчанию видны карточки менеджеров, список открывается кликом по менеджеру.

**Касание** — наше исходящее действие: сообщение менеджера или бота в чат Открытой линии либо звонок. Сообщения клиента касанием не считаются. Если клиент написал позже нашего последнего касания, запись помечается «клиент ждёт ответа». Исходящие, которые Wazzup записывает от имени клиента с пометкой «=== Исходящее сообщение», считаются нашими.

## Как работает

- `collector.js` собирает снимок из Bitrix24 через входящий вебхук: лиды и сделки, привязанные чаты Открытых линий, последние сообщения и звонки. Только чтение, в Bitrix ничего не пишет.
- `server.js` раз в 15 минут обновляет снимок, хранит последний удачный в памяти и отдаёт страницу и `/api/snapshot` под HTTP Basic-авторизацией.
- `public/index.html` запрашивает снимок раз в минуту и пересчитывает время без касаний на месте.
- `build-static.js` — локальная версия без сервера: собирает снимок и вшивает его в HTML-файл.

Внешних зависимостей нет, нужен Node.js 22+. Сбор занимает около 2 минут.

## Переменные окружения

| Переменная | Обязательна | По умолчанию | Что это |
|---|---|---|---|
| `BITRIX_WEBHOOK` | да | — | URL входящего вебхука, `https://<портал>.bitrix24.ru/rest/<id>/<ключ>/`. Права: crm, imopenlines, im, user, department. |
| `DASHBOARD_PASSWORD` | да, для сервера | — | Пароль для входа на дашборд. |
| `DASHBOARD_USER` | нет | `mygenetics` | Логин для входа. |
| `DEPARTMENTS` | нет | `256,198` | ID подразделений Bitrix через запятую (Группа продаж B2C МСК и НСК). |
| `DEAL_CATEGORY_ID` | нет | `27` | ID воронки сделок («В2С Продажа»). |
| `THRESHOLD_HOURS` | нет | `48` | Порог «без касаний» для лидов, часов. |
| `DEAL_THRESHOLD_DAYS` | нет | `30` | Порог «без касаний» для сделок, дней. |
| `REFRESH_MINUTES` | нет | `15` | Как часто собирать данные. |

Вебхук и пароль задаются только в переменных Railway, в репозиторий их не коммитим: репозиторий публичный.

## Railway

1. Variables: задать `BITRIX_WEBHOOK` и `DASHBOARD_PASSWORD`.
2. Settings → Networking → Generate Domain.
3. Healthcheck path: `/healthz`, он отвечает без пароля и без данных.

После запуска первый сбор идёт около 2 минут, в это время страница показывает «Первый сбор данных».

## Локально

```sh
BITRIX_WEBHOOK=... DASHBOARD_PASSWORD=... npm start      # сервер на http://localhost:3000
BITRIX_WEBHOOK=... node build-static.js dashboard.html   # один HTML-файл с данными
```
